# Ganesh C — Premium Portfolio

A responsive ivory-and-cream personal portfolio built with React + Vite.

## Run locally
1. Install Node.js 20+.
2. Extract this project.
3. Open a terminal in the project folder.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL printed by Vite.

## Add your profile photo
Copy your preferred profile photo into `public/` and name it exactly:
`ganesh-profile.jpg`

The hero section currently displays a graceful initials placeholder until the image is added.

## Resume
`public/Ganesh_C_Resume.pdf` is included and linked from the navigation and hero section.

## Customize
- Update personal links and project URLs in `src/main.jsx`.
- Update styling and colors in `src/styles.css`.
- Build for deployment with `npm run build`.
- Deploy the generated `dist/` folder to Vercel or Netlify.
